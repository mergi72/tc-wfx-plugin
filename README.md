# tc-wfx-plugin

Separated C# repository for the Total Commander WFX plugin that integrates with `dms-provider-bridge`.

## Structure

- `src/TcWfxPlugin/` - plugin implementation project
- `tests/TcWfxPlugin.Tests/` - test project placeholder

## Notes

- This machine currently has no .NET SDK installed, so build/test commands are not yet available.
- After installing .NET SDK 8.0+, run:

```powershell
dotnet --info
dotnet build
```
